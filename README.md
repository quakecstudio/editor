# QuakeC Studio

A native, cross-platform IDE for QuakeC, the scripting language of id Software's original *Quake*, written in Rust. It has Zed's editor feel and Roblox Studio's play loop: edit code, press Play, and see the change in the running game in about a second. It ships its own QuakeC compiler (no outside toolchain), a built-in agent that edits, compiles and tests through the same commands as the UI (also exposed over MCP), and a map editor with its own map compiler.

## Status

Released. The MVP, [`v2026.11.1`](https://github.com/quakecstudio/editor/releases/tag/v2026.11.1), shipped on 2026-11-20 when Phase 4's gate was signed off, and later versions are on the [releases page](https://github.com/quakecstudio/editor/releases), each with packages for macOS, Windows and Linux.

All eight phases (0 to 7) are built and their gates are closed, each with a report in [`docs/gates/`](docs/gates/). That covers the QuakeC VM and formats, the compiler (checked against FTEQCC and id's `qcc` on the rerelease and public mods), the language server, the `quakec-ide` command line, the code editor, the live preview, the built-in agent, release packages (the macOS package is signed and notarized, the Windows executables and the Linux rpm are signed), and a map editor. The map editor does entity and brush editing, textured and lit views, and has our own map compilers with coloured light, region compile and a background full compile, checked against id's tools and ericw-tools. What is left is the Post-MVP backlog; its largest piece is the Windows and Linux desktop checks ([#851](https://github.com/quakecstudio/editor/issues/851)). Work is tracked as GitHub issues generated from [`plan/`](plan/README.md), on the [project board](https://github.com/orgs/quakecstudio/projects/1).

## Building

With [rustup](https://rustup.rs/) installed (the toolchain is pinned in `rust-toolchain.toml`):

```bash
cargo build --locked
cargo test --locked
```

[`CONTRIBUTING.md`](CONTRIBUTING.md) lists every check a change must pass. Report security
problems as [`SECURITY.md`](SECURITY.md) describes.
