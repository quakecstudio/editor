# Readiness: P2 L2 syntax (P2-R2)

- **Issue:** #83 (`P2-R2`)
- **Reviewer:** an independent Claude agent session (the `reviewer` subagent); did not write
  the layer's code
- **Date:** 2026-10-24
- **Commit reviewed:** `dc0e5fd4bcb52bb76f7e7a12c75bb950d5c843fe` (`main`, after #570 and #572), all
  four crates
- **Commit of the last Readiness measurement:** `40f42b054771cbd973c34b9a37001853a8e788f2` (see
  section 2)
- **Verdict:** Not ready

This is the seventh review of the layer. The sixth (commit `40f42b0`) failed it on P2-130, P2-131
and P2-132. #570 (P2-130, the `extern` block) and #572 (the macro table under `caseinsens`, with
the type-name fix P2-131) closed the two L2 defects: this review re-ran their programs and found
them fixed, and found the L2 parser still reads a family of declarations narrower than FTEQCC's.
Every issue the readiness issue depends on was closed when this review started.

This review ran about 1,400 programs of its own through the builtin differential against the
pinned FTEQCC, in four batches written around the constructs the last three reviews found
defects in: `extern` blocks, `-Fcaseinsens` names in every position and the macro table,
directives and pragmas, flags that change in the middle of a file, and keywords. Most agree. The
differences are of five kinds (section 3); **two are defects of this layer**, both in the
parser's grammar for `struct`, `union`, `class` and `typedef`, filed as **P2-133**
(`type:feature`, L2). The semantic model's differences are filed as **P2-134** against P2-R3
(#84), and P2-132 (open) stays P2-R3's. Each blocks readiness.

No new Readiness run was taken for this review. The Readiness workflow run dispatched for it at
`dc0e5fd` ([40094712627](https://github.com/quakecstudio/editor/actions/runs/40094712627)) was
set aside on the coordinator's instruction, because #562 and #559 change `qc-preproc` and
`qc-project` and so the run would not measure the final L2 code; the combined run that replaces
it measures a layer that cannot pass until P2-133 is fixed. The numbers in section 2 are the
last complete measurement, of `40f42b0`, which met the whole bar; the eighth review, after
P2-133, measures again and commits the ratchets.

The review added seven passing tests (section 5).
