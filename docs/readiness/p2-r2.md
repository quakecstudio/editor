# Readiness: P2 L2 syntax (P2-R2)

- **Issue:** #83 (`P2-R2`)
- **Reviewer:** an independent Claude agent session (the `reviewer` subagent); did not write
  the layer's code
- **Date:** 2026-10-26
- **Commit reviewed:** `COMMIT_REVIEWED` (`main`, after #581), all four crates
- **Commits measured:** `cc910935a1186e12bdd00909d762a1ee971c9c17` (qc-lexer, qc-project),
  `66cc901833e02dfbfef1b325b4db446a3589b74e` (qc-preproc) and `COMMIT_REVIEWED` (qc-syntax);
  see section 2
- **Verdict:** VERDICT

This is the eighth review of the layer. The seventh (commit `dc0e5fd`) failed it on P2-133, the
parser's grammar for `struct`, `union`, `class` and `typedef`, which #581 (P2-133 and P2-134's
L2 half, with the `types` family of the builtin differential) closed. This review re-ran the
seventh review's programs and found them fixed, then wrote about 2,700 programs of its own
around the same grammar and found one more parser defect, a definition whose type is a typedef
of a function type (section 5), which #581 fixed before it merged on this review's report; the
review re-ran its probes on the merged commit. Every issue the readiness issue depends on was
closed when the report was written.

The numbers in section 2 come from three Readiness runs on `main`, one per set of crates, since
the layer's crates reached their final code in three merges: #584 for qc-preproc and #581 for
qc-syntax came after the first run measured qc-lexer and qc-project. Each crate's numbers are
of the last commit that changed it.

The review added five passing tests (section 5) and filed the semantic model's differences it
found as P2-145 against P2-R3 (#84).

## 5. Independent review (TEST-9)

- **Reviewer and time spent:** an independent Claude agent session, about four hours of work.
  It built the oracles on macOS arm64 (`cargo xtask oracles build`), read `QCC_PR_ParseDefs`,
  `QCC_PR_ParseType`, `QCC_PR_ParseStruct`, `QCC_PR_ParseEntClass` and `QCC_PR_ParseEnum`
  against the parser's `typedef_decl`, `struct_type`, `struct_declarator`, `class_body`,
  `class_member`, `declarator` and `lost_brace`, ran the programs of section 3, and ran the four
  crates' suites locally (961 tests, all passing, on `9aefebc`).
- **The seventh review's defects, re-checked.** P2-133: every program of its seven groups is a
  case of the `types` family, which the Unit Tests job of #581 ran on each OS with 0 unexplained
  differences; this review's own batch holds the same forms with the neighbours above and they
  agree. P2-134 and P2-132 are open and are L3's.
- **Defect found** (blocks readiness; fixed in #581 before it merged, commit FIX_COMMIT, and
  re-checked by this review on `COMMIT_REVIEWED`): the parser kept each declared type name
  without its shape, so a definition whose type is a typedef of a function type took an
  expression after `=` and no body, state header or builtin. Each row is FTEQCC's outcome
  against the profile's on `9aefebc`:

  | Program | FTEQCC | Profile | Fix |
  | --- | --- | --- | --- |
  | `typedef void() fn; fn g = { return; };`, `fn g = { ; };`, `fn g = { float x; };`, `fn g = { g(); };`, `typedef float(float) fn; fn g = { return 1; };`, `typedef void(float a) fn; fn g = { a = 1; };` | a function | E0204 "expected function arg list", E0203 | #581 |
  | `typedef void() fn; fn g = #6;`, `fn g : 6;` | a builtin | E0506 "initialiser is not a constant" | #581 |
  | `typedef void() fn; fn g = [1, g] {};`, `$frame a1` then `[$a1, g]` | a state function | E0204 | #581 |
  | the same with `static`, `var`, in a body and after `local`, as a class member (`fn m = { return; }`, `virtual`, `static`, `fn C::m = { return; };`), as a struct's `static` or `virtual` member, in `extern "C" { }` and `extern "QC" { }`, through `typedef fn fn2;` and `#define FN void()`, and with the typedef in the body | a function | E0204, E0203 | #581 |
  | `typedef void() fn; fn g = { 1 };` | a body with "expected ;" | an aggregate, accepted | #581 |
  | `typedef float (t);`, `typedef float t; typedef t (u);` | "expected function arg list" (FTEF-19.35) | accepted | #581 |

  Only `fn g = {}` agreed before the fix, read as an empty aggregate.
