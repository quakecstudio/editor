# Readiness: P2 L1 VM (P2-R1)

- **Issue:** #456 (`P2-R1`)
- **Reviewer:** an independent Claude agent session (the `reviewer` subagent); did not write
  the layer's code
- **Date:** 2026-10-20
- **Commit measured:** `23e98c27b1b3fed96c933ac6584176685ac4b26d` (`main`, after #453), and
  `97590fc0b36828e59ca5b44af369bf28f775cc25`, the same with this review's tests (the head of this PR's first commit)
- **Verdict:** Ready

This review reopens L1 under TEST-11. P1-R1 (`docs/readiness/p1-r1.md`) counted ADR-0013's
zero-divergence bar as met on id 1.01, while the nightly Differential run diverged on every
rerelease codebase at its first `ftos` call. #453 (P2-61, #455) found the cause in the
differential host: it wrote no string record when a builtin set the `ftos`/`vtos` buffer, which
TRACE-4.10 and DIFF-3.8 require, so the comparison read the buffer's value as bits. The fix is
in `qc-builtins`' mock (`EngineStrings::take_temp_change`) and `qs-differential`'s host, with
the new statement DIFF-3.9.

On `main` the layer is short of its ratchet in one place: qc-vm's mutation score is 90.8% (208
of 229), below the 91% P1-R1 committed, with three survivors neither killed nor recorded. #397,
which landed after P1-R1, made `Builtins::engine_string` a required method and gave `NoBuiltins`
its own body, `None`, whose three `Some(...)` mutants no test reached. This review's first
commit adds the test that kills them (a string opcode on an out-of-table value under
`NoBuiltins` is the VM-7.3 run error), and the Readiness run on that commit passes all 35 checks of `cargo xtask ratchet`, qc-vm's mutation at 92.1% (211 of 229).
With the whole corpus at zero divergences against id's VM and the `qc-vm` fuzz target clean
after #453, the layer is ready.

## 5. Independent review (TEST-9)

- **Reviewer and time spent:** an independent Claude agent session, about an hour on L1, after
  the L2 and L3 re-reviews of the same session. It read #453's diff against TRACE-4.10, DIFF-3.8
  and DIFF-3.9 and BUILTIN-7.4, checked the differential evidence on `main`, measured the layer
  on `main` and on this branch, and ran `cargo mutants` on the survivors.
- **Tests added** (six, all passing):
  - `crates/qc-vm/src/tests/adversarial.rs`:
    - `reviewer_no_builtins_resolves_no_engine_string` (VM-7.3): `EQ_S`, `NE_S` and `NOT_S` on
      an out-of-table value under `NoBuiltins` are the VM-7.3 run error; kills the three
      survivors.
    - `reviewer_an_engine_strings_text_is_read_at_each_comparison` (VM-7.3): a builtin that
      rewrites the one buffer between two `EQ_S` changes the second result, and `NE_S` then
      gives `'t' - 'o'`.
  - `crates/qc-builtins/src/tests.rs`:
    - `reviewer_ftos_then_vtos_share_one_buffer` (BUILTIN-7.4): `vtos` after `ftos` over one
      engine returns the same value, the earlier result's text becomes `vtos`'s, and DIFF-3.9's
      change is reported once with it.
    - `reviewer_repeated_ftos_reports_a_change_only_for_new_text` (DIFF-3.9): through dispatch,
      `ftos` of 5, 5, 6, 6, 5 reports a change for the first, third and fifth only.
    - `reviewer_made_strings_survive_the_temp_buffer` (EDICT-13.3): made strings and the buffer
      take distinct values in either order, and the buffer's text changes leave theirs alone.
  - `crates/qc-trace/src/tests.rs`: `reviewer_negative_engine_string_values_resolve`
    (TRACE-7.3): string records for -1 and -2 survive a binary round trip and each value names
    its latest text.
- **Defects found:** the mutation decay above, fixed by this review's test and re-measured in
  [39352740531](https://github.com/quakecstudio/editor/actions/runs/39352740531). No defect in the VM's or the builtins' behaviour: every probe of the engine-string
  paths matched the spec.
