## Findings

Each is something a strict reading could hold against the gate, so each is stated as the review found it, followed by what Justin's sign-off of 2026-11-20 settled.

1. **The gate text in `plan/backlog/_meta.yaml` still says "on all three OSes".** #136's acceptance was narrowed to macOS on 2026-11-16, but the milestone's gate text was not amended, as Phase 3's was at its close (PR 786). There is no Windows or Linux evidence for the demo, and none is claimed. **Settled:** the gate is P4-25's acceptance. This PR amends the gate text to "on macOS (Windows and Linux are L-16)", in `_meta.yaml` and in the roadmap's phase table; L-16 (#851) stays open.
2. **The demo's agent was an MCP client, not the built-in agent.** The weapon was added by Claude Code over `quakec-ide mcp --connect`. The agent panel with a model provider (P4-06, P4-07, P4-09) has never been recorded doing the gate's task: the hand run did not use it, and no model has run the evals. #135 was closed on its criteria as written, and its record says this plainly. The gate text says "the agent adds a weapon"; whether an MCP client agent is "the agent" is Justin's reading to make. The demo also ran from `cargo build --release` builds at 30683ba7, not from the published `.pkg`, and "no window was looked at by a person". **Settled:** Justin signed the gate off with this stated; the built-in agent panel doing the task with a model is still unrecorded.
3. **#1034's fourth criterion has a second half with no run behind it.** "a pre-release's run pushes neither and opens none": the comment on #1034 of 2026-11-20 cites `v2026.11.1-rc1`'s run. That run, [43053533387](https://github.com/quakecstudio/editor/actions/runs/43053533387), is from 2026-11-11 at a21fbf18, a week before PR 1033 (06035af8, 2026-11-18) added the three publishing jobs; its job list has none of them. So it shows nothing about a pre-release skipping them. What stands for it is the condition in `.github/workflows/release.yml` (`github.ref_type == 'tag' && !contains(github.ref_name, '-')`) and the pull-request dry runs, where `PUBLISH` is false. No pre-release tag has been pushed since PR 1033. **Settled:** #1034 was closed on that condition and the dry runs, and its closing comment says no run shows it. The first pre-release tag after this will be the first run to show it.

Smaller, not blocking:

- The scheduled Benchmarks run [43898479297](https://github.com/quakecstudio/editor/actions/runs/43898479297) of 2026-11-16 failed on the 10% rule for `entities_outliner`. `perf-mvp.md` leaves it "for the next scheduled run to show"; none has run since.
- `docs/roadmap.md`, "Where we are", still lists the license review, the macOS acceptance and the release as waiting. This PR brings it up to date.
- MVP-2 ("Phases run in order; each gate must pass before the next phase starts"): the gates of Phases 5, 6 and 7 closed on 2026-11-12, 2026-11-15 and 2026-11-16, before this one. The plan allows it for the MVP gate, which a person closes (`CLAUDE.md`, "How work is organised").
