# Phase 5 gate: map entity editing

Gate issue: [#150](https://github.com/quakecstudio/editor/issues/150) (P5-09). Reviewed 2026-11-12 against `main` at a643f0f, by a reviewer session that did not write Phase 5's code. **Verdict: not met; escalated.** The gate criterion itself is proven: entities in existing maps are edited with definitions derived from the QuakeC, and the edits reach the running game, on macOS, Windows and Linux. Every issue in the milestone is closed and no PR is open. One closed issue's acceptance criterion has no evidence: P5-08 (#149) asks that "The agent places three Shamblers in a named room from a prompt in an eval", and no model has ever run that eval, because the Evals workflow has never run and the `QS_EVAL_API_KEY` secret is not set. Only Justin can set the secret or change the criterion, so the gate stays open; see [What is missing](#what-is-missing).

`plan/backlog/_meta.yaml`, milestone P5:

P5-09's acceptance restates it as "Gate met: entities in existing maps edited with QuakeC-derived definitions and appearing live". Its deliverable is `docs/gates/p5.md`.
