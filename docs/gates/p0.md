### Criteria met by a decision rather than as written

These do not block the gate. They are recorded so that nothing is silently waived.

- **P0-10:** the spike ran on the Mac only. ADR-0003, decided by Justin, moved the Windows and Linux runs to P2-17's acceptance, real IME input to P2-18 and screen readers to P2-23. The plan's P0-10 acceptance says so, and those P2 issues carry them.
- **P0-12:** "each candidate built and run on all three OSes" was not done. Justin chose option D, our own Rust host, in ADR-0004, and ADR-0005 then removed every outside engine. No C candidate is used, so the builds would decide nothing. ADR-0004 still says the build logs go on the issue before acceptance. Under ADR-0001 an accepted ADR is not rewritten, so that sentence stays.
- **P0-22:** the recorded launches were not made before acceptance. Justin accepted ADR-0008 on the engine-source reading. The launches are now P3-06's acceptance, against the preview host only (ADR-0005).

## For Phase 1

- **The schedule is not yet tested on code.** The target dates come from Phase 0's measured rate, and Phase 0 was mostly documents and decisions. Phase 1 is the first phase under the readiness bar, with 24-hour fuzzing, full mutation runs and 20-run flake jobs. The Phase 1 gate should re-date the roadmap from Phase 1's actual duration.
