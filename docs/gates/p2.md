# Phase 2 gate: language core and editor

Gate issue: [#80](https://github.com/quakecstudio/editor/issues/80) (P2-24). Closed on 2026-11-04 by Justin's decision to focus on the MVP and move to Phase 3, on the evidence below rather than a further independent review round.

## The gate

> the rerelease compiles with our compiler and leaves the same qc-vm traces as the FTEQCC-built rerelease; full navigation and clean diagnostics in the editor

## Evidence

| Part | Evidence |
| --- | --- |
| The rerelease compiles with qc-codegen and behaves as FTEQCC's | The nightly compiler differential compiles each corpus codebase with both compilers and calls every function from the scenario worlds: all six rerelease codebases, id 1.01 and the corpus mods at the bar pass on PR 701's code (run 41877684070; Arcane Dimensions was still running). 10,000 generated programs of seed 1 agree apart from 178 proved FTEQCC defects (#649). `quakec-ide build` builds the rerelease on Linux, macOS and Windows in CI (#69) |
| Navigation and diagnostics in the editor | The editor, the language server and the CLI share the workbench commands (`docs/commands.md`); the P2 readiness reviews are in `docs/readiness/` (p2-r1, p2-r1b, p2-r5, p2-ra and the others) |

## Decisions that closed the phase

- The last readiness rounds (#85, #88, #676) were closed on their recorded evidence, without the further rounds they asked for. Their notes not taken up: Windows UNC paths in the language server and a stronger language-server fuzz target (#88's second round).
- [#644](https://github.com/quakecstudio/editor/issues/644), recording IME composition through a real input method, moved to LATER (`docs/scope.md`). [#87](https://github.com/quakecstudio/editor/issues/87), the L7 readiness review, which waited on it, was closed with the phase.
- From Phase 3 on, each phase has its gate review alone (`docs/testing.md`).
